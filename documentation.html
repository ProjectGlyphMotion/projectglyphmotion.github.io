v4.0 vs v4.5 Architecture Distinction

v4.0 introduced adaptive scene intelligence (UnifiedMode, PID, Temporal Reuse & ROI HFDR). v4.5 keeps those exact perceptual algorithms untouched while removing every serial CPU, GPU, and I/O bottleneck around them.

v4.0 Baseline Adaptive Intelligence

Serial FP32 + Hybrid Sync Loop

  • • Ran single-frame model.track() in FP32 (batch=1, ~37.4 ms/frame).
  • • Executed blocking per-frame CPU optical-flow GMC (~16 ms/frame).
  • • Processed full-frame HFDR buffers, 25 MB .tobytes() copies, and 2-pass audio mux.
  • • Used 5 MB Drive upload chunks and single-thread libvmaf (~50 min at 4K).
v4.5 Overhaul 5-Stage Parallel Engine

Batch-8 FP16 + Zero-Copy Async

  • • Drains up to 8 queued frames per Tensor Core predict() in FP16 (~10.7 ms/f).
  • • Offloads tracking to a dedicated TrackTrack-Fast thread (gmc_method=none, -57.5% ID switches).
  • • Crops ROI HFDR to cv2.boundingRect() (~0.38 ms) and streams zero-copy memoryview to inline NVENC p4.
  • • Streams 128 MB Drive PUTs in parallel with 16-thread libvmaf (~4.2 min at 4K).

How v4.5 Works: 5-Stage Async Pipeline

Every stage executes concurrently across bounded queues (FRAME_QUEUE_SIZE=16, RENDER_QUEUE_SIZE=16), overlapping decode, Batch-8 GPU inference, tracking, HFDR rendering, NVENC encoding, and post-publish benchmarking.

01

Ingestion & Resize

Reads native frames and creates INTER_LINEAR detection frames without blocking inference, respecting rotation & psutil limits.

02

Batch-8 GPU Pass

Drains up to 8 frames (OT_BATCH_SIZE=8) per CUDA FP16 call, removing Python/GPU launch stalls.

03

TrackTrack-Fast

Runs decoupled Kalman/IoU tracking with gmc_method=none + 320×180 motion scoring for UnifiedMode gating.

04

ROI-Slice HFDR

Reinjects (9,9) detail only inside cv2.boundingRect(roi_mask) (~0.38 ms) and paints crisp detection boxes.

05

NVENC + Cloud

Pipes via memoryview to 1-pass hevc_nvenc p4 (inline audio), then overlaps 128 MB Drive PUT w/ 16t VMAF.

Adaptive Scene Intelligence

Shared logic across v4.0 and v4.5 that balances perceptual fidelity, bitrate entropy, and tracking continuity dynamically per scene.

Temporal Reuse Gate

Computes should_reuse_frame(0.003) on 320×180 grayscale deltas. Ultra-static frames reuse cached HF detail—while YOLO inference always runs so track IDs stay continuous.

Semantic ROI Priority

Weights reconstruction alpha by class importance (person/car: 1.0, bike/pet: 0.7, gear: 0.4) with adaptive mask refresh every 1–8 frames.

PID Feedback Loop

Monitors live FPS, motion magnitude, and queue depth to adapt FFmpeg unsharp strength (1.0–2.0) and hfdr_alpha around target throughput.

UnifiedModeController (Hysteresis = 5 frames)

Motion threshold: 0.02 · Object threshold: 3
Mode A — Adaptive Temporal Low motion / Few objects

Skips per-frame ROI HFDR masking and prioritizes temporal stability and maximum frame rate.

Mode B — ROI + Temporal High motion / Complex scenes

Activates cv2.boundingRect ROI-cropped HFDR around detections for maximum edge clarity under motion.

Low ≤0.008 · Med ≤0.025 · High >0.025

1.0 / 0.7 / 0.4 / 0.15

Class importance weights: 3: 1.0 primary targets, 2: 0.7 vehicles/secondary, 1: 0.4 background objects, 0: 0.15 static context.

Flag / Env Default Behavior

OT_BATCH_SIZE / OT_PIPE_PIX_FMT 8 / bgr24 Controls Batch-N tensor size and FFmpeg rawvideo stdin pipe pixel layout.
